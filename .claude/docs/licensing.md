# Licensing rules

No open licence covers Fantasy Flight Games (FFG) / Asmodee TI4 content. Our policy:

1. **Facts only** from external sources: names, numbers (cost, combat, move, res/inf, VP), prerequisites, traits, counts. Facts aren't copyrightable; card *text* is.
2. **All prose is original** paraphrase written for this app. Never paste card text or rulebook text.
3. **No official art, logos, card scans, faction symbols or fonts.** Visuals are our own CSS/SVG; fonts are OFL (Inter, Rajdhani, Orbitron via @fontsource).
4. Always show the "unofficial fan project, not affiliated with FFG/Asmodee" disclaimer (Home, Settings, faction/card pages).
5. Non-commercial; free to use.

Sources used for facts:
- AsyncTI4 / TI4_map_generator_bot (`src/main/resources/data/**`) — software under the Unlicense; we read only factual fields (see `scripts/extract-facts.py`). Game content there remains FFG's.
- Not used: scottmk/ti4-reference (CC-BY-4.0) — could be used with attribution if needed later.

French terminology is our own (no official FR glossary used): e.g. trade goods = "biens commerciaux", commodities = "marchandises". Card and unit names stay in English; keyword abilities (SUSTAIN DAMAGE…) stay in English inside French text.
